# Kokonut UI

Registry: `@kokonutui` (`https://kokonutui.com/r/{name}.json`) — configured in `components.json`.

- Install via CLI: `npx shadcn@latest add @kokonutui/<name>` (never copy-paste).
- Components install to `components/kokonutui/` as project source; edit in place rather than wrapping.
- Styling uses Tailwind CSS v4 and `cn()` from `@/lib/utils`.
- Requires React 19 and Motion (`motion/react`).
