# Brand: THE COMMIT BOOK (W1-brand, 2026-11-05)

## Recommendation
**The Commit Book** (thecommitbook.com). Product = athlete stories ("how they committed") + playbooks ("the book"). Short, ownable, athletic ("commit" is the moment every story ends on). "The Recruiting Calendar" kept as a product/feature name inside the site (the dated rules calendar), not the brand, because a competitor already advertises a free "recruiting calendar" PDF and NCAA publishes official "Recruiting Calendar" PDFs, so the phrase is generic and unprotectable.

## Logo system (hand-authored SVG, generator `logo/gen.cjs`)
- **Mark:** open-book outline whose spine notches form a down-chevron (bookmark/"drop the commit") with a check inside = "committed". Rounded black square container. Not a swoosh, no stripes, no figure.
- **Wordmark:** custom condensed block caps (geometric, no font dependency), "THE" small above "COMMIT BOOK".
- Files: `mark-{light,dark}.svg`, `wordmark-*`, `lockup-horizontal-*`, `lockup-stacked-*`, `social-card-*` (1200x630), `favicon.svg` (16px simplified, thicker strokes); PNG previews in `logo/png/`.

## Usage rules
- Black #000 / white #FFF only. Accent color, if any, belongs to the site system, never inside the logo.
- Clear space = height of "THE" around all lockups. Min size: mark 16px (use favicon.svg below 32px), wordmark 120px wide.
- Don't stretch, outline, add shadows, rotate, or put the mark on photos without a solid black/white plate.
- Social card tagline is set in system Helvetica/Arial bold (live text); convert to outlines before external print use.
- Stories integrity rules (BRIEF-V3) apply to any brand imagery: no generated likeness of real athletes.
