# Worksheet 6: Follow log

*Rules and scripts for families to use themselves. The Commit Book does not contact coaches, place athletes or promise introductions, replies or offers. Verify every date on the NCAA page for your sport.*

Open `6-follow-log.csv` in any spreadsheet. One row per touch.
- channel: email, dm, questionnaire, camp_in_person, call, own_coach_intro
- reply_type: none, form_auto, staff_generic, coach_personal, film_request, visit_invite, not_recruiting
- Dates: YYYY-MM-DD. Run `python3 kit_cli.py log-check 6-follow-log.csv` to validate and list what is due.
Counts you get are self-reported. Do not quote them as results.
